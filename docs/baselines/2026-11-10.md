## Runs (last 7 days)

| Metric | Value |
|---|---|
| Orchestrator invocations | 87 |
| Salvage produced the report (`salvage_outcome = 'ok'`) | 53 (61%), avg 26.8 s |
| Forced finalize (`finalize_started`) | 25 (29%) |

| Starting context (`initial_context_chars`) | avg 169,725 / max 268,841 |
| Avg clustering time at run end (`cluster_ms > 0`) | 3.3 s |

```sql
select count(*) as runs,
  count(*) filter (where salvage_outcome = 'ok') as salvaged,
  count(*) filter (where finalize_started) as forced_finalize,
  round(avg(step_count)::numeric, 1) as avg_steps,
  round(avg(initial_context_chars)) as avg_init_ctx,
  max(initial_context_chars) as max_init_ctx,
  round(avg(salvage_ms) filter (where salvage_ms > 0)) as avg_salvage_ms,
  round(avg(cluster_ms) filter (where cluster_ms > 0)) as avg_cluster_ms
from orchestrator_invocations
where started_at > now() - interval '7 days';
```
